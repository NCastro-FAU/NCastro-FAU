This Github was created as a small backup of my main work, tackling MR-related problems I face during my day-to-day. 

About me:
MRI physicist, PhD candidate at University Hospital Erlangen / FAU Erlangen-Nürnberg.

I write MRI sequences and the reconstructions that go with them: mainly non-Cartesian and reconstruction (basic SENSE,
TV/TGV, L1, LLR + SSR, Toeplitz on GPU), trajectory and gradient-impulse-response (GIRF) correction, Maxwell corrections, B0 corrections
and Pulseq sequence programming.

**Repositories**
- [MIC](https://github.com/NCastro-FAU/MIC---Motion-Informed-Coil-Selection): motion-informed coil selection for speech MRI (ISMRM 2026)
- [mri-recon-tutorials](https://github.com/NCastro-FAU/mri-recon-tutorials): GRAPPA, ESPIRiT, PICS, B0 correction, navigator corrections, unrolled DL recon, from scratch
- [mri-apple-silicon-gpu](https://github.com/NCastro-FAU/mri-apple-silicon-gpu): MRI reconstruction on Apple GPUs with MLX and PyTorch MPS (NUFFT, Toeplitz PICS)
- [pulseq-mrzero-sequences](https://github.com/NCastro-FAU/pulseq-mrzero-sequences): GRE, radial and spiral in PyPulseq, simulated with MR-zero

**Tools:** Python (NumPy, PyTorch, MLX), Pulseq, BART, MATLAB, Siemens scanners mainly (0.55 T Free.Max, 3 T Cima.X)
